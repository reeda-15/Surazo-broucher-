# Surazo website

Independent brochure-led website for Surazo, a brand of Ulhas Buildtech Pvt. Ltd. All product imagery and the downloadable PDF originate from the user-provided brochure. This project is separate from every other internship project.

## Preview

Serve `dist` with a static HTTP server, for example `python -m http.server 4173 --directory dist`. No dependency installation or build is required. Edit `dist/index.html`, `dist/styles.css`, and `dist/app.js` directly.

## Enquiries

The quote form prepares a WhatsApp message or email draft for the visitor to review and send. No form data is stored or transmitted to a project backend. Product buttons preselect the product; load-class enquiries preselect the selected grade. The site does not claim that opening a draft sends the enquiry.

## Content

Company experience and installation counts come from the brochure. No additional certification badges, unverified performance guarantees, prices, testimonials, or customer logos are invented. Load-class content does not reproduce the brochure's simplified per-wheel loading claim or ambiguous concrete bedding dimension. Product suitability and documentation are confirmed with the manufacturer.

Google Fonts supplies Manrope and DM Sans, with sans-serif fallbacks. Product images are local WebP files; the original brochure is available at `assets/surazo-brochure.pdf`.
